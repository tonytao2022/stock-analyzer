## 驾驶舱展示方案（驾驶舱页面下半部分，单卡片）

### 布局：1行标题 + 1行指标汇总 + 5行对比表格

```
┌─────────────────────────────────────────────────────┐
│  🔬 评分引擎消融实验（反事实对比）                     │
├─────────────────────────────────────────────────────┤
│  完整引擎 ████████████████████  +12.3%  胜率55.2%   │  ← 基准线
├─────┬────────┬────────┬──────┬──────┬───────────────┤
│ #   │ 实验组  │ 收益Δ  │ 回撤  │ 胜率 │  因子贡献度   │
├─────┼────────┼────────┼──────┼──────┼───────────────┤
│  1  │ 关技术分│ -4.2%  │ -9.2% │51.0% │ ████ 结构分   │
│  2  │ 关资金流│ -2.8%  │ -8.7% │53.1% │ ███ 资金流   │
│  3  │ 关情绪  │ -1.5%  │ -8.9% │54.8% │ █ 情绪       │
│  4  │ 关惩罚  │ -3.1%  │ -8.2% │52.5% │ ████ 惩罚    │
│  5  │ 关季节  │ -0.8%  │ -8.6% │54.9% │ █ 季节       │
└─────┴────────┴────────┴──────┴──────┴───────────────┘
```

### 关键设计决策

1. **收益Δ列用条件颜色**：负值红色 + 向下箭头，正值绿色 + 向上箭头
2. **回撤列仅用数字**：不额外着色，因为是全部分组都用同一基准对比
3. **胜率列**：高于基准用绿色，低于基准用红色
4. **因子贡献度列**：横向条形图，每行显示该实验组被关闭的那个因子贡献的分数（即delta_diagnostics中对应该因子的值）
5. **基准线**：灰色横条，标注"完整引擎"并高亮总收益和胜率——让Tony一眼看出哪个去掉效果最差

### 显示规则

| 条件 | 处理 |
|:----|:-----|
| 收益Δ绝对值<0.5% | 显示 "≈0"（视作无影响） |
| 实验组>5组 | 默认只显示TOP5影响最大的，展开按钮看全部 |
| 因子贡献度数值 | 保留1位小数，正负号明确 |
| 回撤恶化（比基线更深） | 红色标注，数值前加 - |
